- XSS: React 텍스트 렌더, `dangerouslySetInnerHTML` 금지. 상세 텍스트의 줄바꿈은 `white-space: pre-wrap`으로만 처리
- 도구명·태그는 링크화하지 않음 (피싱 URL 삽입 무해화)

## 상태 (`workflows`)

```
draft(클라이언트 초안, DB 없음) ──저장──> published(is_public=true) <──토글──> private(is_public=false)
                                          │                                  │
                                          └──admin hidden=true──> hidden(소유자만) ──admin hidden=false──> (원 상태)
소유자 delete / 탈퇴 cascade → 삭제 (모든 상태에서)
```
DB 표현 = `is_public` × `hidden` 두 boolean — 위 다이어그램과 1:1 (draft는 DB 밖).
