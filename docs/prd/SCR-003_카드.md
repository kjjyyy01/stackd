## 1. 개요
- **목적**: 카드 비주얼 결판(액센트·공개 여부) + **저장 게이트**(BR-016). `card_preview`(EVT-CARD-002, 보조) 발생점 · **저장 성공 = `card_create`(EVT-CARD-001, H-01)** 발생점. 라우트 `/card`, 인증 없음 → 저장 시 GitHub 로그인 (PRD-04)
- **구현 기능**: F-004(미리보기·액센트·유도 버튼), F-005(저장·공개/비공개), F-002(초안 복원·OAuth 왕복 보존)
- **입력 원천**: 빌더 값은 전부 SCR-001에서 받아 초안(BR-019)으로 넘어옴 — 이 화면은 accent·is_public만 바꾼다. 소속·역할은 표시만

## 3. 기능 요구사항
### REQ-CARD-001: 카드 미리보기 실시간 렌더 (P0)
- **AC-1 (정상)**: Given 초안(단계 ≥2) 존재, When `/card` 진입, Then EL-CARD-002~008이 초안 값으로 렌더(BR-019 복원)되고, 세션 있으면 EL-CARD-005에 GitHub 핸들·아바타, 없으면 placeholder(CPY-CARD-104). EL-CARD-009는 비활성 상태로 노출
- **AC-2 (검증 실패)**: Given 초안 없음·손상·버전 불일치·단계 <2, When 진입, Then 손상분 폐기(BR-019, 안내 없음) + `/`로 리다이렉트 (Empty)
- **AC-3 (서버 오류)**: 해당 없음 — 렌더는 클라이언트. 세션 조회(서버 컴포넌트)가 실패하면 비로그인으로 렌더
- **AC-4 (오프라인)**: 미리보기·EL-CARD-010·011 정상 (전 로직 클라이언트)

### REQ-CARD-002: 액센트 컬러 선택 (P0)
- **AC-1 (정상)**: When EL-CARD-010 클릭, Then 카드에 즉시 반영 + 초안 `accent` 갱신 (BR-019)
- **AC-2 (검증 실패)**: Given 초안 `accent`가 팔레트 외 슬러그, Then 기본값으로 표시·저장 (PRD-05 `accent` 규칙)
- **AC-3 (서버 오류)**: 해당 없음 — 서버 호출 없음 / **AC-4 (오프라인)**: 정상

### REQ-CARD-003: 공개/비공개 선택 (P0)
- **AC-1 (정상)**: Given 기본 켜짐(BR-017), When EL-CARD-011을 끄면, Then CPY-CARD-015 노출 + 초안 `is_public=false` — 저장 시 그대로 전달
- **AC-2 (검증 실패)**: 해당 없음 — boolean 선택식
- **AC-3 (서버 오류)**: 해당 없음 — 값은 REQ-CARD-004의 `saveWorkflow` 입력에 포함 / **AC-4 (오프라인)**: 정상

### REQ-CARD-004: 저장 — 로그인 게이트 (P0)
- **AC-1 (정상 · 로그인)**: Given 세션 && 게이트 충족(BR-016), When EL-CARD-012(CPY-CARD-012) 클릭, Then `saveWorkflow(draft, editId?)` 호출 → 성공 시 CPY-CARD-017 토스트 + **EVT-CARD-001(`card_create`, 신규) 또는 EVT-CARD-003(`card_edit`, 수정)** + 초안 삭제(BR-019) + `/card-detail/{id}` 이동
- **AC-1 (정상 · 비로그인)**: Given 세션 없음 && 게이트 충족, When EL-CARD-012(CPY-CARD-013) 클릭, Then 초안 보존 확인 → `signInWithOAuth({provider:'github', options:{redirectTo: origin + '/auth/callback?next=' + encodeURIComponent('/card?save=1')}})` (PRD-06) → 콜백 성공 후 `/card?save=1` 복귀 → 세션 && 게이트 충족이면 **자동 저장 시도** (결과는 위와 동일)
- **AC-2 (검증 실패)**: Given 제목/상황 빈 값 또는 단계 <2 또는 단계 메모/상세 빈 값(BR-013·014), Then EL-CARD-012 비활성 + EL-CARD-013(CPY-CARD-002, ERR-CARD-001). 서버 재검증 거부(`{ok:false, code:'ERR-CARD-001'}`, BR-007) → 동일 문구 토스트, 초안 유지
- **AC-3 (서버 오류)**: DB·RLS·id 충돌 3회(BR-023) → ERR-CARD-004 토스트(CPY-CARD-010) + 버튼 재활성(재시도), 초안 유지 / 세션 만료 → ERR-AUTH-001 → 비로그인 흐름으로 재진입 (PRD-09) / OAuth 실패·취소 → 콜백이 `/?auth=failed`로 보냄 → 홈에서 ERR-CARD-005 토스트(CPY-CARD-011), 초안 유지 → SCR-001 CTA로 `/card` 재진입
- **AC-4 (오프라인)**: `navigator.onLine=false` → EL-CARD-012 비활성, 복귀 시 재활성. 미리보기·컨트롤은 정상

### REQ-CARD-005: `card_create` 발화 (P0 — H-01)
- **AC-1 (정상)**: Given 단계 ≥2 초안, When `/card` 진입, Then EVT-CARD-002(`card_preview`) **로그인 여부 무관 1회** 발화 (`step_count`). `?save=1` 복귀 로드에서는 미발화 (중복 방지)
- **AC-2 (검증 실패)**: 단계 <2 → 미발화 (리다이렉트)
- **AC-3 (서버 오류)**: GA4 전송 실패는 침묵 (PRD-15) / **AC-4 (오프라인)**: 발화 시도만, UX 영향 없음

## 9. API 호출
- `saveWorkflow(draft, editId?)` — 서버 액션 (PRD-06 §쓰기). 실패 코드 ERR-AUTH-001 / ERR-CARD-001 / ERR-CARD-004
- Supabase `signInWithOAuth` (클라이언트) + GET `/auth/callback?code=&next=` (PRD-06 §라우트 핸들러) — 비로그인 저장 흐름
- 세션 조회 — 서버 컴포넌트 `getUser()` → 핸들·아바타를 미리보기 props로 (PRD-05 §auth.users)
- `togglePublic` 해당 없음 — 저장 전이라 `is_public`은 `saveWorkflow` 입력에 포함

## 13. 비기능
- **즉시 반영**: 스와치·스위치 → 카드 렌더 동기 반영, 디바운스 없음
- **위생**: h1 1개·`<main>/<section>`. 골격(h1·라벨·버튼)은 서버 HTML, 카드 데이터만 초안 하이드레이션. `"use client"` = 미리보기+컨트롤 래퍼 1개, 세션은 서버 컴포넌트에서 props로
- **성능**: LCP ≤2.5초 (골격 기준). 카드 컴포넌트는 SCR-004·라이브러리·내 카드와 **1벌**(세로형); OG는 가로 별도 구성(OQ-012)
- **메타데이터**: PRD-04 §메타데이터 표 — **noindex**
