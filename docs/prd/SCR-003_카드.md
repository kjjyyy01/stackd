## 1. 개요
- **목적**: 제품의 승부처 — "공유하고 싶어지는" 비주얼의 결판 지점. 라우트 `/card`. 킬 지표 2종(EVT-CARD-001/002) 발생점
- **구현 기능**: F-004(미리보기·커스터마이즈), F-005(PNG/링크 공유)

## 3. 기능 요구사항
### REQ-CARD-001: 실시간 미리보기 (P0)
- **AC-1 (정상)**: Given 스택 ≥1개로 진입, When 닉네임·소속(선택) 입력·액센트 변경, Then 미리보기 즉시 반영 + 진입 시 EVT-CARD-001 발화 1회
- **AC-2 (검증 실패)**: Given 닉네임 미입력, Then 타이틀 placeholder(`Your Stack`) + 액션 2개 비활성 + CPY-CARD-002 (ERR-CARD-001)
- **AC-3 (서버 오류)**: 해당 없음 — 클라이언트 렌더
- **AC-4 (오프라인)**: 정상 동작 (전 로직 클라이언트)

### REQ-CARD-002: PNG 다운로드 (P0)
- **AC-1 (정상)**: Given 닉네임 입력됨, When 다운로드 클릭, Then PNG 저장 트리거 + EVT-CARD-002(`share_method=png_download`) 발화
- **AC-2 (검증 실패)**: 닉네임 게이트 (REQ-CARD-001 AC-2)
- **AC-3 (생성 실패)**: Given 이미지 생성 예외, Then ERR-CARD-002 토스트 + 재시도 버튼, 이벤트 미발화
- **AC-4 (오프라인)**: 정상 동작 (클라이언트 생성)

### REQ-CARD-003: 공유 링크 복사 (P0)
- **AC-1 (정상)**: Given 닉네임 입력됨, When 복사 클릭, Then PRD-05 §URL 페이로드로 인코딩한 `/stack?s=` 절대 URL 클립보드 복사 + CPY-CARD-004 토스트 + EVT-CARD-002(`share_method=link_copy`)
- **AC-2 (검증 실패)**: 닉네임 게이트
- **AC-3/4**: 클립보드 실패 시 토스트로 URL 표시 폴백 / 오프라인 복사 정상

### REQ-CARD-004: QR로 건네기 (P0 — 대면 공유, "만든 이유"의 핵심 장면)
- **AC-1 (정상)**: Given 닉네임 입력됨, When QR 버튼 클릭, Then 다이얼로그에 QR 표시(인코딩 = `/stack?s=…&utm_source=card&utm_medium=qr` 절대 URL) + EVT-CARD-002(`share_method=qr`) 발화. 상대가 기본 카메라로 스캔 → `/stack` 착지
- **AC-2 (검증 실패)**: 닉네임 게이트
- **AC-3/4**: 해당 없음(클라이언트 생성) / 오프라인 QR 표시 정상 (스캔 측은 네트워크 필요)

## 4. 화면 상태 (Lite 4종)
| 상태 | UI |
|---|---|
| Loading | 해당 없음 — 클라이언트 상태 즉시 렌더 |
| Empty | 스택 0개 직접 진입: 홈으로 안내 (EVT-CARD-001 미발화) |
| Loaded | 미리보기 + 컨트롤 (닉네임 유무로 액션 활성/비활성) |
| Error | PNG 생성 실패: 토스트 + 재시도 (화면 유지) |

## 5. 사용자 행동
| 액션 | 트리거 | 결과 |
|---|---|---|
| 닉네임 입력 | 타이핑 | 미리보기 타이틀 반영, 10자 초과 차단 |
| 소속·역할 입력 (선택) | 타이핑 | 서브타이틀 반영, 비우면 미표시 (BR-008) |
| 액센트 변경 | 스와치 클릭 | 미리보기 컬러 반영 |
| 다운로드/복사/QR | 버튼 (닉네임 필수) | EVT-CARD-002 (`share_method`로 구분) |

## 13. 비기능
- 미리보기 반영 체감 즉시 (입력 디바운스 없이), PNG 생성 수 초 내
- 콘텐츠 서버 렌더 위생: 이 화면은 상태 의존 인터랙션 화면 — noindex(PRD-04)로 예외 처리, 정적 골격(헤딩·라벨)은 서버 렌더 유지
