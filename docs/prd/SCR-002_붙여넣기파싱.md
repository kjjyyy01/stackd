## 1. 개요
- **목적**: 설정 텍스트 붙여넣기 → 스택 후보 추출 (검색·선택보다 빠른 보조 경로 — grill Q1). 별도 라우트 없음 — SCR-001의 탭
- **컷 지위**: **컷 1순위** (Day 9 판정 시 최우선 삭제). 삭제 시 탭 UI가 단일 모드로 축소되는 것 외 다른 화면 영향 0이어야 한다 — **SCR-001과 상태 공유 외 결합 금지**

## 2. 레이아웃 & 구성 요소
| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
|---|---|---|---|---|
| EL-PARSE-001 | 붙여넣기 영역 | textarea | Y | CPY-PARSE-001 placeholder |
| EL-PARSE-002 | 추출 버튼 | 버튼 | Y | 빈 textarea 시 비활성 |
| EL-PARSE-003 | 추출 결과 피드백 | 인라인 메시지 | Y | CPY-PARSE-002/003 |

## 3. 기능 요구사항
### REQ-PARSE-001: 텍스트 추출 (P1 — AC 2종)
- **AC-1 (정상)**: Given 2형식 중 하나 붙여넣음, When 추출 클릭, Then BR-005 판별 규칙대로 인식 항목이 스택에 선택 반영(12개 상한 내) + CPY-PARSE-003 + EVT-PARSE-001 발화, 담긴 항목마다 EVT-BLDR-001(`method=paste`)
- **AC-2 (검증 실패)**: Given 그 외 텍스트, When 추출, Then 0건 — ERR-PARSE-001 폴백(골라 담기 유도) + EVT-PARSE-001(`parse_format=unknown, extracted_count=0`)

## 4. 화면 상태 (Lite 4종)
| 상태 | UI |
|---|---|
| Loading | 해당 없음 — 동기 클라이언트 파싱 |
| Empty | textarea 빈 상태 + placeholder |
| Loaded | 추출 결과 피드백 + 스택 바 반영 (SCR-001과 공유) |
| Error | 해당 없음 — 인식 실패는 Error가 아니라 폴백 안내 (BR-005) |
