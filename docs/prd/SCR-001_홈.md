> **v3.0.0 (2026-08-25, Day 8)**: 히어로를 풀뷰포트 캐러셀로 개편 — Day 7 동결 시안이 레이아웃 SSOT. 페이지 순서 = [초안 배너] → 캐러셀(슬라이드 1이 히어로) → 카드 쇼케이스 → 과정 레일 → 빌더 → 푸터 + FAB. 미결 6건 판정(2026-08-25 사용자 확정): LCP 후보 h1로 변경 / 클라 경계 3곳 / 배너 헤더 아래 전역 / GA4 슬라이드 이벤트 없음(7종 동결) / FAB 홈 전용 / 스와이프 힌트 미채택(OQ-013 — Day 14 검증)

## 1. 개요
- **목적**: 가치 전달(캐러셀 히어로 + 쇼케이스 + 과정 레일) + 워크플로우 작성 시작을 한 화면에서. 라우트 `/`, 수정 모드 `/?edit={id}` (PRD-04). 인증 없음 — 수정 모드만 소유자(PRD-09)
- **구현 기능**: F-001(빌더 — 제목·상황·상황 상세·단계·개발 스택 태그·소속/역할, 순서 변경), F-002(초안 자동 저장·복원 + 수정 모드 로드). F-008 수정은 이 화면이 로드 담당(저장은 SCR-003)
- **하지 않는 것**: 서버 쓰기(저장은 SCR-003 `saveWorkflow`), 닉네임 입력(BR-025), 상황 추천 칩(BR-011), 타인 카드 프리필(BR-024), 캐러셀 자동 재생, 별도 작성 페이지 `/new`(판정일 이후 재검토)

## 3. 기능 요구사항
### REQ-HOME-001: 기본 정보 입력 — 제목·상황·상황 상세 (P0)
- **AC-1 (정상)**: Given 빈 빌더, When 제목 1~30자·상황 1~20자 입력, Then 카운터 갱신 + 초안 저장(REQ-HOME-005) + 게이트 조건 충족 표시
- **AC-2 (검증 실패)**: Given 입력 중, When 31자 제목 / 21자 상황 / 1,001자 상세 입력, Then 값 반영 차단 + 인라인 ERR-BLDR-003·ERR-BLDR-004·ERR-BLDR-005 (blur 후 표시). 이모지·특수문자는 허용(BR-003)
- **AC-3 (서버 오류)**: 해당 없음 — 이 화면은 서버 쓰기 없음. 서버 재검증은 SCR-003 `saveWorkflow`(BR-007 공용 유틸)
- **AC-4 (오프라인)**: Given 페이지 로드 완료 후 오프라인, When 입력, Then 정상 동작 (전 로직 클라이언트)

### REQ-HOME-002: 단계 추가 — 도구 선택 (P0)
- **AC-1 (정상)**: Given 단계 <8, When 검색 → 결과 클릭, **또는 검색 결과 유무와 무관하게 직접 입력 전환 → 이름+카테고리 → 확정**, Then 단계 행 생성(맨 뒤) + EVT-BLDR-001(`method=catalog`|`manual`) 발화 + 선택기 닫힘
- **AC-2 (검증 실패)**: Given 단계 8개, When 추가, Then 차단 + ERR-BLDR-001 / Given 직접 입력, When 빈 이름·41자, Then 확정 차단 + ERR-BLDR-002 인라인
- **AC-3 (서버 오류)**: 해당 없음 — 카탈로그 정적 import
- **AC-4 (오프라인)**: 정상 동작

### REQ-HOME-003: 단계 편집 — 메모·상세·순서·삭제 (P0)
- **AC-1 (정상)**: Given 단계 ≥2, When 위/아래 클릭, Then 배열 순서 교환(첫 행 위·끝 행 아래는 비활성) / When 삭제, Then 즉시 제거(확인 없음, 초안으로 복구 가능) / When 메모·상세 입력, Then 해당 단계에 반영
- **AC-2 (검증 실패)**: Given 입력 중, When 메모 61자 / 상세 501자, Then 차단 + ERR-BLDR-005 / When 메모 또는 상세가 빈 채로 CTA, Then CTA 비활성 + 해당 단계에 CPY-HOME-030 인라인 (BR-013·014 필수)
- **AC-3 (서버 오류)**: 해당 없음
- **AC-4 (오프라인)**: 정상 동작

### REQ-HOME-004: 개발 스택 태그 · 소속/역할 (P0)
- **AC-1 (정상)**: Given 태그 <4, When 검색·선택, **또는 검색 결과 유무와 무관하게 직접 입력 전환 → 이름+카테고리(3종) → 확정**, Then 칩 추가(중복 불가 — `name` trim 기준, 재클릭 해제)
- **AC-2 (검증 실패)**: Given 태그 4개, When 5번째, Then 차단 + ERR-BLDR-006 / Given 스택 직접 입력, When 빈 이름·41자, Then 확정 차단 + ERR-BLDR-002 인라인 / Given 소속 입력, When 21자, Then 차단 + ERR-CARD-003 (선택 필드 — 게이트 아님. 이모지·특수문자는 허용 BR-003)
- **AC-3 (서버 오류)**: 해당 없음 — 서버 쓰기 없는 화면
- **AC-4 (오프라인)**: 정상 동작

### REQ-HOME-005: 초안 자동 저장·복원 (P0 — F-002, BR-019)
- **AC-1 (정상)**: Given 입력 변경, When 상태 바뀔 때마다, Then localStorage `stackd:draft`(PRD-05 §클라이언트 초안) 갱신 / Given 유효 초안, When `/` 진입, Then EL-HOME-004를 **헤더 아래 전역 위치**에 노출 → 이어서 쓰기 = `#builder` 스크롤 + 전 필드 복원 / 새로 시작 = 초안 삭제 + 빈 빌더
- **AC-2 (검증 실패)**: Given 손상·`v` 불일치 초안, When 진입, Then 조용히 폐기 + 배너 없음
- **AC-3 (서버 오류)**: 해당 없음 — 클라이언트 전용
- **AC-4 (오프라인)**: 정상 동작. 초안 삭제는 SCR-003 저장 성공 시(BR-019) — 이 화면은 삭제하지 않음(새로 시작 제외)

### REQ-HOME-006: 수정 모드 로드 (P0 — F-002, F-008 연계)
- **AC-1 (정상)**: Given 로그인 소유자, When `/?edit={id}` 진입, Then 서버 컴포넌트가 `workflows` by id 조회(PRD-06 §읽기) → 전 필드 + `accent`·`is_public` 빌더에 로드, 초안 `editId` 설정 → 이후 CTA·저장은 update 경로
- **AC-2 (검증 실패)**: Given 비소유자·미로그인·없는 id, When 진입, Then RLS로 0행 → 빈 빌더, 안내 없음, `editId` 미설정 (PRD-06)
- **AC-3 (서버 오류)**: Given 조회 예외, When 진입, Then AC-2와 동일 처리(빈 빌더) — 안내 없음
- **AC-4 (오프라인)**: 해당 없음 — 서버 렌더 경로(브라우저 오프라인 페이지)

### REQ-HOME-007: CTA 게이트 (P0)
- **AC-1 (정상)**: Given 제목·상황 유효 + 단계 ≥2, When CTA 클릭, Then `/card` 이동 (상태는 초안 경유 — SCR-003이 BR-019로 복원)
- **AC-2 (검증 실패)**: Given 단계 <2, Then CTA 비활성 + CPY-HOME-002 / Given 단계 ≥2이나 제목·상황 빈 값, Then CTA 비활성 + 해당 필드 인라인 ERR-BLDR-003·ERR-BLDR-004
- **AC-3 (서버 오류)**: 해당 없음
- **AC-4 (오프라인)**: 초안은 보존, `/card` 이동은 Next 클라이언트 라우팅 몫(프리페치 시 정상)
- 게이트 대상은 EL-HOME-014만 — EL-HOME-022(히어로 CTA)는 `#builder` 앵커라 게이트·비활성 없음

### REQ-HOME-008: 캐러셀 탐색 (P1 — 2026-08-25 신설)
