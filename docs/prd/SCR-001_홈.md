## 1. 개요
- **목적**: 가치 전달과 생성 시작을 한 화면에서 (랜딩·빌더 분리는 전환 손실 — day2). 라우트 `/`
- **구현 기능**: F-001(검색·선택), F-002(직접 입력)

## 3. 기능 요구사항
### REQ-HOME-001: 카탈로그 검색·선택 (P0)
- **AC-1 (정상)**: Given 카탈로그 로드됨, When 검색어 입력 후 항목 클릭, Then 담은 스택 바에 추가되고 EVT-BLDR-001(`method=catalog`) 발화
- **AC-2 (검증 실패)**: Given 12개 담김, When 13번째 클릭, Then 추가 차단 + ERR-BLDR-001 안내
- **AC-3 (서버 오류)**: 해당 없음 — 카탈로그는 정적 import, 서버 의존 0
- **AC-4 (오프라인)**: Given 페이지 로드 완료 후 오프라인, When 검색·담기, Then 정상 동작 (전 로직 클라이언트)

### REQ-HOME-002: 직접 입력 (P0)
- **AC-1 (정상)**: Given 카탈로그에 없는 도구, When 이름+카테고리 입력 후 담기, Then 스택 추가 + EVT-BLDR-001(`method=manual`) 발화
- **AC-2 (검증 실패)**: Given 빈 이름 또는 41자, When 담기, Then 차단 + ERR-BLDR-002 인라인 에러
- **AC-3/4**: REQ-HOME-001과 동일 (해당 없음/오프라인 정상)

### REQ-HOME-003: CTA 게이트 (P0)
- **AC-1 (정상)**: Given 스택 ≥1개, When CTA 클릭, Then `/card` 이동 (상태 유지)
- **AC-2 (검증 실패)**: Given 스택 0개, Then CTA 비활성 + CPY-HOME-002 노출

## 4. 화면 상태 (Lite 4종)
| 상태 | UI |
|---|---|
| Loading | 해당 없음 — 정적 import, 비동기 로드 없음 |
| Empty | 스택 0개: CTA 비활성 + CPY-HOME-002 (기본 진입 상태) |
| Loaded | 스택 ≥1개: 담은 스택 바 + CTA 활성 |
| Error | 해당 없음 — 실패할 네트워크 요청 없음 |

## 5. 사용자 행동
| 액션 | 트리거 | 결과 |
|---|---|---|
| 항목 담기 | 그리드 클릭 / 직접 입력 담기 | 스택 추가 + EVT-BLDR-001 |
| 항목 해제 | 스택 바 칩 × | 스택 제거 (이벤트 미발화) |
| 모드 전환 | 탭 클릭 | 골라 담기 ↔ 붙여넣기 (스택 유지) |
| 카드 만들기 | CTA (스택 ≥1) | `/card` 이동 |
