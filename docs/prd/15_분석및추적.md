# 15 분석 및 추적 — EVT SSOT (GA4 명세)

> DB가 없으므로 **GA4가 유일한 데이터 저장소**다. 킬 크라이테리아 판정(H-01·02, 런칭+14일)이 전부 이 스펙 위에서 이뤄진다.
> 설정: 측정 ID는 `NEXT_PUBLIC_GA_ID` 환경변수 (Day 0 생성 계정 — 속성·ID 확인은 사용자 작업).

## 공통 규칙

- 네이밍: snake_case, 이벤트명·파라미터명 ≤40자, 파라미터 값 ≤100자, 예약 접두사(`google_`/`ga_`/`firebase_`) 금지
- ⚠️ 규격 이탈 신고: 스킬 스펙의 "과거형" 규칙 대신 **Day 1 확정명(`card_create`/`card_share`) 유지** — 킬 크라이테리아·PLAN이 이 이름으로 동결됨, 상위 문서 승
- PII 금지 — 자유 텍스트 파라미터는 `item_name` 하나(도구명 용도). 닉네임은 **수집하지 않는다**
- `page_view`는 향상된 측정이 자동 수집 — `/stack` 조회는 page_view(path=/stack)로 충분, 커스텀 이벤트 금지. "나도 만들기" 클릭은 UTM이 계수 — 클릭 이벤트 없음. **커스텀 이벤트는 아래 4종이 전부**
- 발화 실패는 침묵 — 트래킹 에러가 UX를 막지 않는다

## 이벤트 카탈로그

| EVT-ID | 이벤트명 | 발화 시점 (화면) | 파라미터 | 측정 대상 |
|---|---|---|---|---|
| EVT-BLDR-001 | `stack_add` | 항목이 스택에 추가되는 순간 (SCR-001) — 해제·재담기 미측정 | `method`: `catalog`\|`manual`\|`paste` / `item_category`: enum 7종 (BR-004) / `item_name`: 도구명 | 중간 퍼널 |
| EVT-PARSE-001 | `paste_parse` | "추출" 클릭 결과 확정 시 (SCR-002) | `parse_format`: `settings_json`\|`claude_md`\|`unknown` / `extracted_count`: 숫자 | 파싱 인식률 |
| EVT-CARD-001 | `card_create` | `/card` 진입 && 스택 ≥1개 (SCR-003) — 빈 진입 미발화, 진입당 1회 | `stack_count`: 숫자 | **H-01** |
| EVT-CARD-002 | `card_share` | PNG 다운로드 성공·클립보드 복사 성공·QR 다이얼로그 열기 (SCR-003) — 실패 시 미발화 | `share_method`: `png_download`\|`link_copy`\|`qr` / `accent`: 액센트 슬러그 / `stack_count`: 숫자 | **H-02** |

역할 주석:
- EVT-BLDR-001: H-01 미달 시 "담기 자체를 안 한다"(가치 전달 실패) vs "담고도 카드를 안 만든다"(빌더→카드 마찰)를 구분하는 유일한 중간 퍼널. `method=manual`의 `item_name`은 **카탈로그 누락 후보 수집 채널** (day1 v2 성장 구조 — DB 없이 GA4가 대행)
- EVT-PARSE-001: `unknown`·`extracted_count=0` 비율 = AI 파싱(backlog) 승격/영구 보류의 판정 데이터

## UTM 규격

| 경로 | UTM | 용도 |
|---|---|---|
| `/stack` → 홈 CTA | `utm_source=card&utm_medium=share` | 루프 작동 직접 증거 (H 보조) |
| `/stack` → "내 카드 수정하기" (본인만) | `utm_source=card&utm_medium=edit` | 본인 재편집 유입 (F-008) — 신규 생성과 분리 계수 |
| QR 인코딩 URL | `utm_source=card&utm_medium=qr` | **대면 확산 vs 온라인 확산 분리 계수** — "명함처럼 쓰이는가"의 판정 데이터 (backlog 타입 선택 모드의 결정 근거) |
| 런칭 포스트 (Day 18~19) | `utm_source=disquiet` / `geeknews` + `utm_medium=community` | 채널 효과 구분 |

- 내부 링크 UTM은 세션 어트리뷰션을 리셋하지만 여기선 의도된 동작 — 카드 경유 재진입을 "card 채널 신규 유입"으로 계수하는 것이 목적. 원 유입 소스가 덮이는 비용은 판정에 영향 없음

## 커스텀 디멘션 등록 (사용자 작업 — GA4 콘솔, Day 15~16까지)

등록 없이는 표준 보고서에서 파라미터가 안 보인다. 이벤트 범위 디멘션 5개 + 측정항목 1개 (한도 50 중 6):
`method` / `item_category` / `parse_format` / `share_method` / `accent` + 측정항목 `stack_count`
(`item_name`·`extracted_count`는 탐색 분석용 — 등록 보류, 필요 시 추가)

## 킬 크라이테리아 대조표 (판정일 실행 절차)

| 기준 | 수치 | GA4 확인 방법 |
|---|---|---|
| H-01 생성 전환 ≥15% | `card_create` 발생 총 사용자 ÷ 전체 총 사용자 | 탐색: 세그먼트 "card_create 발생" 총 사용자 / 전체 |
| H-02 확산 ≥30명 | `card_share` 발생 총 사용자 | 탐색: 동일 방식 |
| 표본 ≥300명 | 전체 총 사용자 | 탐색: 총 사용자 (활성 사용자 아님) |
| 보조: 루프 작동 | `session_source=card` 세션 수 | 보고서 → 트래픽 획득: 세션 소스/매체 = `card / share` |
