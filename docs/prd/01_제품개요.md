# 01 제품 개요 — 기획서 v2 승계 + F/H ID

## 만든 이유 (2026-08-17 확정 문구)

> **도구는 아는데, 어떻게 쓰는지는 모른다.**
> 실제 개발자들이 어떤 상황에서, 어떤 순서로 agent를 쓰는지 — 워크플로우를 카드 한 장으로 공유하세요.

agent 도구(skills·plugins·MCP·agents·marketplaces)를 *뭘* 쓰면 좋은지는 알려져 있지만 *어떻게 응용해서* 쓰는지 예시가 적다. 여러 개발자의 실제 워크플로우가 카드로 만들어져 **라이브러리**에 모이면, 비슷한 상황의 개발자가 그대로 써볼 수 있다. 자랑·명함이 아니라 **공유·권유** ("나는 이런 상황에 이렇게 써 — 비슷하면 써봐").

## 제품 한 줄

개발자가 자기 Agentic workflow(상황 + 순서 있는 단계 + 도구 + 개발 스택 컨텍스트)를 **카드(요약) + 상세 페이지(설명)** 로 만들어 링크로 공유하고, 라이브러리에서 다른 개발자의 예시를 본다. 한국어 UI · 카드 라벨/도구명 영어 · 사용자 텍스트는 입력 언어 그대로 · **만들기·보기는 비로그인, 저장부터 GitHub 로그인** · Supabase(Auth+DB+RLS). v1은 Claude Code 생태계 한정, 개발 스택은 컨텍스트 태그.

**포지셔닝**: "내 워크플로우를 카드로 공유" — 카드 톤은 명함급 고급감(여백·타이포)을 가져가되 **명함은 톤일 뿐 사용 장면이 아니다** (대면 QR·연락처·명함첩 없음, 2026-08-16).

**가드**: ① 타인 워크플로우 **포크·프리필 기능 없음** (사용자 결정 — 백로그 재검토 시 소유권·출처 표기 전제) ② 이메일 등 PII는 카드·상세·OG 어디에도 노출하지 않음 — 작성자 표기는 GitHub 핸들·아바타 스냅샷만 ③ 명함 구성요소 기능화(연락처·명함첩)·대면 QR은 backlog ④ 라이브러리는 최신순 목록뿐(검색·필터·좋아요 backlog).
