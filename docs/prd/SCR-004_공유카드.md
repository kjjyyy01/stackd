- **목적**: 확산 루프 착지점 — 링크 수신자가 카드를 보고 "나도 만들기"로 재진입. 라우트 `/stack?s=` (day2의 `/c`에서 Day 3 변경)
- **구현 기능**: F-006 (카드 렌더 + 동적 OG + CTA)

## 3. 기능 요구사항
### REQ-SHARE-001: 페이로드 디코드·렌더 (P0)
- **AC-1 (정상)**: Given 유효한 `s`, When 접속, Then BR-001~004·007 제한 적용 후 카드 서버 렌더 (콘텐츠가 HTML에 존재 — JS 없이 텍스트 노출)
- **AC-2 (검증 실패)**: Given `s` 손상·누락, Then ERR-SHARE-001 — 홈 안내 렌더 (에러 화면·5xx 아님)
- **AC-3 (서버 오류)**: Given 렌더 예외, Then Next.js error boundary → 홈 링크 포함 에러 페이지
- **AC-4 (오프라인)**: 최초 접속은 네트워크 필수 — 브라우저 기본 오프라인 화면 허용

### REQ-SHARE-002: 동적 OG (P0)
- **AC-1 (정상)**: Given 유효한 `s`, Then `generateMetadata`가 title `{닉네임}'s Stack | Stackd` + `og:image=/api/og?s=` 설정 (PRD-06)
- **AC-2 (검증 실패)**: Given `s` 손상, Then 기본 title + 정적 기본 OG (ERR-OG-001 경로)
- **AC-3/4**: OG 함수 5xx여도 페이지 렌더는 무관 (분리) / 해당 없음

### REQ-SHARE-003: 재진입 CTA (P0)
- **AC-1 (정상)**: When CTA 클릭, Then `/?utm_source=card&utm_medium=share` 이동 — GA4 세션 소스 `card / share` 계수 (PRD-15 §UTM)
- **AC-2~4**: 해당 없음 (정적 링크)
