## 1. 개요
- **목적**: 확산 루프 착지점 + 카드에 없는 긴 설명(상황 상세·단계별 설명). `card_share`(H-02) 발생점. 라우트 `/card-detail/{id}` — 서버 컴포넌트가 id로 조회(PRD-06 §읽기), 공개는 누구나·index, 비공개는 소유자만, **hidden은 모두에게 블러 플레이스홀더 + 사유**(BR-006·017·018, PRD-09)
- **구현 기능**: F-006(상세 렌더·동적 OG·"나도 만들기") / F-007(PNG 저장·링크 복사) / F-011(신고 dialog) / F-008 중 소유자 액션(수정·삭제·공개 전환 — 목록은 SCR-007)

## 3. 기능 요구사항
### REQ-WF-001: 상세 조회·접근 제어 (P0 — F-006)
- **AC-1 (정상)**: Given 공개·!hidden 워크플로우, When 비로그인 포함 누구나 접속, Then 서버 렌더 HTML에 EL-WF-001·003~007 텍스트 포함, 소유자면 EL-WF-009 추가
- **AC-2 (검증 실패)**: Given 없는 id · 형식 불일치(BR-023) · 비공개(타인), When 접속, Then `notFound()` 404 (ERR-SHARE-001, BR-006 — 존재 비노출) / Given hidden(타인·비로그인), Then **EL-WF-011 블러 플레이스홀더 + CPY-WF-015(사유)** 렌더, 내용·액션 미렌더, noindex / Given 소유자, When 비공개·hidden 접속, Then 내용 렌더 + EL-WF-002 배지
- **AC-3 (서버 오류)**: Given Supabase 조회 예외, Then error boundary(홈 링크) — 404로 위장하지 않음
- **AC-4 (오프라인)**: 해당 없음 — 최초 접속은 서버 렌더라 네트워크 필수. 로드 후 오프라인은 REQ-WF-002·003·005·006에서 처리

### REQ-WF-002: PNG 저장 (P0 — F-007)
- **AC-1 (정상)**: Given 카드 로드, When CPY-WF-002 클릭, Then 클라이언트 라이브러리(OQ-002)로 카드 DOM(세로형) 렌더 → blob → `<a download="stackd-{id}.png">` (OQ-008 해소 — `/api/og` 재사용 안 함, PRD-06) → 성공 시 EVT-SHARE-001(소유자)/002(타인)(`share_method=png_download`)
- **AC-2 (검증 실패)**: Given 소유자가 비공개·hidden 카드 열람, Then 클라이언트 렌더라 PNG **정상**(공개 여부와 무관 — 기본 이미지가 되는 것은 og:image뿐). Given 타인이 hidden 카드, Then 버튼 자체 미노출(§11 #3)
- **AC-3 (서버 오류)**: Given 라이브러리 렌더 예외·blob 예외(폰트·아바타 이미지 미로드 등), Then ERR-SHARE-002 토스트 + 재시도, EVT 미발화
- **AC-4 (오프라인)**: Given 로드 후 오프라인, When 클릭, Then 클라이언트 렌더라 정상 동작 가능 — 미캐시 자원(아바타)으로 예외 시 AC-3 동일

### REQ-WF-003: 링크 복사 (P0 — F-007)
- **AC-1 (정상)**: When CPY-WF-003 클릭, Then `navigator.clipboard.writeText('https://stackd.kr/card-detail/{id}')` → CPY-WF-004 토스트 + EVT-SHARE-001(소유자) 또는 EVT-SHARE-002(타인)(`share_method=link_copy`)
- **AC-2 (검증 실패)**: Given 클립보드 API 거부·미지원, Then ERR-SHARE-003 → CPY-WF-006 폴백(URL 표시), EVT 미발화
- **AC-3 (서버 오류)**: 해당 없음 — 서버 호출 없음
- **AC-4 (오프라인)**: 정상 동작 (클립보드는 로컬)

### REQ-WF-004: "나도 만들기" CTA (P0 — F-006)
- **AC-1 (정상)**: Given 타인·비로그인, When EL-WF-007(CPY-WF-001) 클릭, Then `/?utm_source=card&utm_medium=share` 이동 — 커스텀 이벤트 없음(UTM 계수, PRD-15) / Given 소유자, When EL-WF-007(CPY-WF-016) 클릭, Then **`/` 이동 — UTM 없음**. 소유자는 CTA를 숨기지 않는다(헤더에 생성 진입점이 없어 유일한 경로가 로고가 된다) — 계측만 끈다
- **AC-2 (검증 실패)** / **AC-3 (서버 오류)**: 해당 없음 — 단순 링크
- **AC-4 (오프라인)**: 이동 실패는 브라우저 기본 처리

### REQ-WF-005: 신고 (P1 — F-011)
- **AC-1 (정상)**: Given EL-WF-008 열림, When 1~500자 입력 후 전송, Then `submitFeedback('report', body, id)` → CPY-COMMON-002 토스트 + dialog 닫힘 (BR-021 — workflow id 자동 첨부, PII 필드 없음)
- **AC-2 (검증 실패)**: 빈 값·501자 → 전송 비활성 + 카운터; 서버 재검증 실패 → ERR-FB-001
- **AC-3 (서버 오류)**: 저장 실패 → ERR-FB-001 토스트, dialog·입력 유지 (웹훅 실패는 성공 처리)
- **AC-4 (오프라인)**: 서버 액션 실패 → AC-3 동일

### REQ-WF-006: 소유자 액션 (P0 — F-008)
- **AC-1 (정상)**: Given 세션 `user_id` = `workflows.user_id`, Then EL-WF-009 노출 → 수정: `/?edit={id}` 이동(SCR-001 로드, F-002) / 삭제: EL-WF-010 확인 → `deleteWorkflow(id)` 성공 → `/me` 이동 / 공개 전환: `togglePublic(id, !is_public)` 성공 → 배지·switch 갱신(`router.refresh`)
- **AC-2 (검증 실패)**: Given 타인·비로그인, Then EL-WF-009 미노출; 서버 액션을 직접 호출해도 소유자 확인 실패 → ERR-ME-001 (BR-024, IDOR 방지 PRD-09) / Given hidden, Then 공개 전환 비활성(BR-018 — 토글해도 타인 404)
- **AC-3 (서버 오류)**: 삭제·토글 실패 → ERR-ME-001 토스트 + 상태 롤백 / 세션 만료 → ERR-AUTH-001
- **AC-4 (오프라인)**: 서버 액션 실패 → AC-3 동일

### REQ-WF-007: 동적 메타데이터·OG (P0 — F-006)
- **AC-1 (정상)**: Given 공개·!hidden, When 크롤러·공유 스크래퍼 요청, Then `generateMetadata` = PRD-04 표(`{title} — @{handle} | Stackd` · description · canonical · index) + `og:image=/api/og?id={id}&v={updated_at epoch}` (캐시 버스팅, PRD-06)
- **AC-2 (검증 실패)**: 비공개·hidden(소유자 렌더) → 정적 기본 OG + noindex / 없음 → 404 메타
- **AC-3 (서버 오류)**: `/api/og` 실패는 라우트 핸들러가 ERR-OG-001로 기본 이미지 반환(5xx 금지) — 이 화면 몫 아님
- **AC-4 (오프라인)**: 해당 없음 — 서버 측

- **조회**: `workflows` by id — RLS "public read" (PRD-05). 소유자 여부 = 세션 `user_id` 비교(서버 컴포넌트)

## 13. 비기능
- **성능**: LCP ≤2.5초 — 카드는 서버 렌더 텍스트(LCP 후보), 아바타는 소형 `next/image`. `/api/og`는 페이지 렌더에 미포함(메타 태그만). `"use client"`는 EL-WF-006·008·009·010만
- **위생**: h1 1개(제목) · `<main>/<section>/<ol>` · 전 콘텐츠 서버 HTML · 공개는 index + 사이트맵(`updated_at` lastmod), 비공개·hidden noindex(PRD-04) · `<img alt>`
- **보안**: RLS 1차 + 서버 액션 소유자 확인 2차(BR-024, PRD-09) · XSS 텍스트 렌더, `dangerouslySetInnerHTML` 금지 · 외부 링크 `rel="noopener noreferrer"` · 이메일 미노출(PRD-14)
- **메타데이터**: PRD-04 §메타데이터 표 (`/card-detail/{id}` 공개·비공개 2행)
