# 14 보안 및 프라이버시

## 인가·데이터 접근
- **RLS 항상 활성** (PRD-05) — 끄고 배포하면 DB가 공개다. Day 5 연결 확인 항목이자 Day 14 보안 4종 ②
- 클라이언트에는 `NEXT_PUBLIC_SUPABASE_URL`·anon key만. **service role 키는 서버 액션 3곳**(feedback 저장·admin·탈퇴)에서만, 번들에 절대 포함 금지 (Day 14 보안 4종 ①)
- 모든 쓰기 = 서버 액션 + 세션 사용자 확인 + 제한 유틸 재검증 (보안 4종 ③). 소유자 확인은 RLS와 서버 액션 이중
- admin 게이트 = env `ADMIN_USER_IDS` 대조, 그 외 404 (존재 비노출)

## 개인정보 (PII)
| 항목 | 수집 | 저장 | 노출 | 삭제 |
|---|---|---|---|---|
| GitHub 이메일 | OAuth로 자동 (Supabase auth.users) | auth.users만 | **어디에도 렌더·전송·로그하지 않음** (카드·상세·OG·GA4·웹훅 전부) | 탈퇴 시 계정 삭제 |
| GitHub 핸들·아바타 | OAuth | workflows 스냅샷 (`author_*`) | 카드·상세·OG·라이브러리 (공개 게시물의 작성자 표기 — 이용약관에 명시) | 탈퇴 시 cascade |
| 소속·역할 | 사용자 입력(선택) | workflows / user_metadata(기본값) | 카드·상세 | 동일 |
| GA4 | 행동 데이터·쿠키 | Google | — | 개인정보처리방침 고지 |
| 신고자 id | 세션 있으면 uuid | feedback.reporter_id | admin만 | 탈퇴 시 남음(익명 uuid) — 처리방침 명시 |

- **탈퇴(삭제권)**: `/settings`에서 즉시 실행, 계정+워크플로우 전부 삭제(BR-020). 되돌리기 없음 — 확인 입력
- 개인정보처리방침·이용약관 = SCR-005 (Day 4~11 내 제작, Day 16 필수 게이트)
- 비공개 카드는 소유자만 (RLS) — id 추측 방어는 8자 hex + 404

## 콘텐츠·남용
- XSS: React 텍스트 렌더, `dangerouslySetInnerHTML` 금지, 링크화 없음
- 모더레이션: 신고 → 웹훅 알림 → `/admin` hidden + 사유(1~200자, 상세 페이지에 모두에게 표기 — 사유 문구에 개인정보·비방 금지, 운영자 책임) (PRD-08 대응표)
- rate limit 없음(v1) — 저장은 GitHub 계정 게이트가 1차 방어. 실사례 시 사용자당 일일 상한(backlog)
- `npm audit` high 이상 조치 + git 이력 시크릿 검사 (Day 14 보안 4종 ④)
