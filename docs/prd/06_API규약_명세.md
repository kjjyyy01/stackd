# 06 API 규약·명세

> 서버 표면이 라우트 1개뿐이라 06(규약)·07(명세)을 한 파일로 통합. 그 외 전 기능은 클라이언트 로직 — "모든 SCR ≥ API 1개" 정합성 검사는 이 아키텍처(day2 판정 ①)에 한해 비적용.

## 공통 규약

- 버저닝·인증·페이징·멱등성 키: 해당 없음 (자체 쓰기 API 0)
- 외부 API 호출: **1** — 신고·문의·피드백 dialog의 폼 서비스 POST (아래). day2 판정 ③ "외부 API 0"의 예외 승인 (2026-08-15, Q14) — AI·과금형 API가 아니라 판정 취지(비용·폴백 리스크)와 무관

## POST 외부 폼 서비스 — 신고·문의·피드백 (OQ-005에서 서비스 선정)

| 항목 | 내용 |
|---|---|
| 용도 | 신고 dialog(SCR-004)·문의/피드백 dialog(전 페이지 푸터) 전송 |
| 필드 | 유형(report/contact/feedback) + 본문 + (신고 시) 카드 URL 자동 첨부. **이메일 등 개인정보 수집 안 함** — 회신 필요 시 사용자가 본문에 자발 기재 |
| 실패 시 | CPY-COMMON-003 토스트 + dialog 유지 (재시도) — 서비스 핵심 기능과 무관하므로 폴백 없음 |
| 관리 | 폼 서비스 대시보드 = v1의 Admin (자체 Admin 페이지·DB는 backlog) |
| 비용 | 무료 티어 내 (월 고정비 상한 4만원 무영향이 선정 조건 — OQ-005) |

## GET `/api/og` — 동적 OG 이미지 (유일한 서버 코드)

| 항목 | 내용 |
|---|---|
| 구현 | next/og `ImageResponse` 라우트 핸들러. `/stack`의 `generateMetadata`가 `og:image = /api/og?s={payload}`로 연결 |
| 입력 | `s` — `05_데이터모델.md` §URL 페이로드와 동일 (디코드·제한 적용도 동일: BR-001~004·007) |
| 출력 | 1200×630 PNG — 카드 렌더 (닉네임·스택·워터마크) |
| 실패 시 | 디코드 실패·렌더 예외 → **정적 기본 OG 이미지 반환** (5xx로 크롤러에 빈 미리보기 주지 않음) |
| 캐시 | 동일 `s` = 동일 이미지 (순수 함수) → `Cache-Control: public, max-age=31536000, immutable` |
| 폰트 | 임베드 폰트 = 라틴 + 한글 서브셋 — BR-003 화이트리스트가 커버 범위를 보장 (Satori는 미등록 글리프를 렌더하지 않음). 서브셋 제작 방식은 OQ-003 |
