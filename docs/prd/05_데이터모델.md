# 05 데이터 모델 (스키마 SSOT)

> DB·저장소 0 (day2 판정 ①). 데이터는 3곳뿐: 정적 카탈로그 / 클라이언트 상태 / URL 페이로드. ERD·인덱스 해당 없음.

## 카탈로그 — `data/catalog.json` (정적, repo 커밋, 빌더가 import)

| 필드 | 타입 | 제약 |
|---|---|---|
| `id` | string | slug, 유일 |
| `name` | string | 1~40자 |
| `category` | enum | **7종** (BR-004, 2026-08-15 피드백 2) — 개발 스택 `language` \| `framework` \| `tool` / AI agent 스택 `skill` \| `plugin` \| `mcp` \| `agent`. 그룹(개발/AI)은 저장하지 않고 category에서 파생 |
| `description` | string | 영어 한 줄 |
| `source` | string | 출처 URL |

- 범위: AI agent 스택 = Claude Code 생태계 한정 100~200개 + **개발 스택 60~80개**(언어·프레임워크·도구 인기순, 2026-08-15 피드백 2) — 수집은 Day 4

## 클라이언트 상태 (React state + **localStorage "내 카드"** — F-008, 2026-08-16 확정)

> 아래 4필드를 하나의 키(`stackd:mycard`, 버전 필드 포함)로 localStorage에 저장한다 = **내 카드**(이 브라우저에서 마지막으로 만든 카드). 빌더 상태가 바뀔 때마다 갱신. 브라우저 로컬이며 서버 저장소가 아니다 — DB·저장소 0 판정 유지. 홈 진입 시 저장분이 있으면 "내 카드 수정하기 / 새로 만들기"(SCR-001). `/stack`에서는 접속자의 저장 카드를 인코딩한 값과 URL `s`가 **일치할 때만** 수정 진입 허용(SCR-004) — 타인 카드는 수정·포크 불가.

| 필드 | 타입 | 제약 |
|---|---|---|
| `stack` | `{name, category}[]` | ≤12개 (BR-001) |
| `nickname` | string | 1~10자 (BR-003) |
| `role` | string | 소속·역할 — **선택 입력** 0~20자 (BR-008). 자유 텍스트: 회사·학교·"Indie Hacker" 뭐든, 비우면 카드 미표시 |
| `accent` | string | 액센트 컬러 슬러그 — 시그니처 템플릿 1종 고정 (2026-08-15 확정, 템플릿 다종은 backlog) |

## URL 페이로드 — `/stack?s=<encoded>`

- 인코딩: JSON → lz-string `compressToEncodedURIComponent`
- **쿼리 파라미터로 확정** (해시 아님) — 동적 OG 서버 함수가 해시를 수신할 수 없음 (day2의 "쿼리/해시" 양자택일 종결)
- 텍스트 자체 포함 (카탈로그 id 참조 아님) — 링크는 카탈로그와 무관하게 영원히 재현 (grill Q3)

| 키 | 값 | 비고 |
|---|---|---|
| `v` | `1` | 페이로드 포맷 버전 — 기존 링크 영속 보장용 |
| `n` | 닉네임 | 디코드 후 10자 절삭 |
| `t` | 액센트 컬러 슬러그 | 미인식 값 → 기본 액센트 |
| `r` | 소속·역할 (선택) | 디코드 후 20자 절삭, 없으면 미표시 |
| `i` | `[[name, category], …]` | 디코드 후 12개·40자 절삭, enum 외 category 무시. enum 7종 확장은 `v` 그대로 `1` (값 추가 = 하위 호환) |

- 크기: 12개 압축 후 수백 자 — URL 한계(~2,000자) 내 (grill Q3)
- 디코드 실패 처리: BR-006 (`ERR-SHARE-001`)
