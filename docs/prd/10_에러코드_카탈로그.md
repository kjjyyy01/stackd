# 10 에러코드 카탈로그 (ERR SSOT)

> 전부 클라이언트 처리 — HTTP 열은 서버 응답이 있는 경우만. 사용자 문구는 `11_UX카피사전.md` ID 참조 (값 복제 금지).

| ERR-ID | HTTP | 발생 조건 | 처리 | 문구 |
|---|---|---|---|---|
| ERR-BLDR-001 | — | 13번째 항목 담기 시도 (BR-001) | 추가 차단 + 안내 | CPY-HOME-003 |
| ERR-BLDR-002 | — | 직접 입력 이름 빈 값/40자 초과 (BR-002) | 담기 차단 + 인라인 에러 | CPY-HOME-004 |
| ERR-PARSE-001 | — | 추출 결과 0건 (BR-005) | 골라 담기 탭 유도 (에러 화면 아님) | CPY-PARSE-002 |
| ERR-CARD-001 | — | 닉네임 미입력/10자 초과/허용 외 문자 (BR-003) | 다운로드·복사 비활성 + 입력 유도 | CPY-CARD-002 (허용 외 문자는 CPY-CARD-005) |
| ERR-CARD-002 | — | PNG 생성 실패 (라이브러리 예외) | 에러 토스트 + 재시도 버튼 | CPY-CARD-003 |
| ERR-CARD-003 | — | 소속·역할 20자 초과/허용 외 문자 (BR-008) | 입력 차단 + 인라인 에러 (액션 게이트 아님 — 선택 필드) | CPY-CARD-007 |
| ERR-SHARE-001 | — | `/stack` 페이로드 손상·누락·디코드 실패 (BR-006) | 홈으로 안내 렌더 (에러 화면 아님) | CPY-SHARE-002 |
| ERR-OG-001 | 200 | OG 렌더 실패 | 정적 기본 OG 이미지 반환 (`06_API규약_명세.md`) | — (사용자 비노출) |
