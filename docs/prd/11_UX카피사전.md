# 11 UX 카피 사전 (CPY SSOT)

> UI 한국어. 카드의 라벨·도구명은 영어, 사용자 텍스트는 입력 언어 그대로. 톤: 간결·구어체 + **"동료에게 내 워크플로우를 권하는 느낌"** (자랑·명함 어휘 없음). 문구 수정은 이 파일에서만. 결번: CPY-PARSE-*, ~~CPY-HOME-007~~/009(v1 내 카드 버튼), ~~CPY-CARD-001~~/005/008/009, CPY-SHARE-*(→ CPY-WF-*).
