# 11 UX 카피 사전 (CPY SSOT)

> UI 한국어. 카드의 라벨·도구명은 영어, 사용자 텍스트는 입력 언어 그대로. 톤: 간결·구어체 + **"동료에게 내 워크플로우를 권하는 느낌"** (자랑·명함 어휘 없음). 문구 수정은 이 파일에서만. 결번: CPY-PARSE-*, ~~CPY-HOME-007~~/009(v1 내 카드 버튼), ~~CPY-HOME-029~~(히어로 이미지 alt — 2026-08-25 캐러셀 개편으로 이미지 요소 삭제), ~~CPY-CARD-001~~/005/008/009, CPY-SHARE-*(→ CPY-WF-*).
> 캐러셀 장면 내부 데이터(0번 카드 제목·단계·태그, 슬라이드 2 배경 도구명 텍스처, 공유 URL 예시)는 카피가 아니라 **0번 카드 데이터**(`lib/hero-card.ts`)·장면 재현물이다 — 이 사전에 등재하지 않는다.
