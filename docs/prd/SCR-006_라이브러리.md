## 1. 개요
- **목적**: 예시가 모이는 곳 — 만든 이유의 실체. 모두의 공개 워크플로우를 최신순으로 보여주고 상세 페이지(SCR-004)로 보낸다. 라우트 `/workflows`, 인증 없음, index (PRD-04)
- **구현 기능**: F-009 (공개·!hidden 워크플로우 최신순 12개 + 더 보기)
- **컷 판정**: **Day 11 컷 1순위** — 카드는 호스팅되므로 링크 공유만으로 루프 성립. 컷 시 헤더 링크(CPY-COMMON-007)·사이트맵에서 제거만 하고 라우트·문서는 남긴다
- **범위 밖**: 검색·필터·정렬·좋아요 (`/backlog.md`). 시드 3~5장은 Day 11까지 (PRD-19)

## 3. 기능 요구사항
### REQ-LIB-001: 공개 워크플로우 목록 (P0)
- **AC-1 (정상)**: Given 공개·!hidden 워크플로우 ≥1, When `/workflows` 진입, Then `created_at desc` 12개까지 EL-LIB-003 렌더, 비공개(BR-017)·hidden(BR-018) 미포함, 항목 클릭 → `/card-detail/{id}`
- **AC-2 (검증 실패)**: Given `?page`가 비정수·0·음수, When 진입, Then page=1로 처리(안내 없음)
- **AC-3 (서버 오류)**: Given Supabase 조회가 `error` 반환, When 진입, Then EL-LIB-006 (ERR-LIB-001) — h1 유지, 재시도 링크
- **AC-4 (오프라인)**: 해당 없음 — 서버 렌더 페이지, 브라우저 기본 오프라인 화면 (앱 처리 없음)

### REQ-LIB-002: 페이지네이션 (P0)
- **AC-1 (정상)**: Given 공개 워크플로우 13개, When 1페이지 로드, Then 12개 + EL-LIB-004(번호 1·2, 다음 활성) 노출 → `2` 클릭 시 `?page=2`에 13번째 1개, 이전 활성·다음 비활성. 정확히 12개(= 1페이지)면 EL-LIB-004 자체 미노출
- **AC-2 (검증 실패)**: Given `?page=n`이 총 페이지 수 초과(count 쿼리로 산정), When 진입, Then `redirect('/workflows')` (Empty 문구 오노출 방지). ⚠️ count 쿼리는 range 쿼리와 분리 실행 — 같은 요청에서 `count: "exact"` + 범위 초과 `range()`를 같이 쓰면 PostgREST가 200 대신 416(PGRST103)을 던져 이 판정 자체가 죽는다(2026-09-06 실측: `from=7·total=6`에서 재현)
- **AC-3 (서버 오류)**: REQ-LIB-001 AC-3과 동일. count 쿼리 실패는 판정을 건너뛰고(리다이렉트 없이) 본문 쿼리로 진행 — 본문도 실패하면 AC-3
- **AC-4 (오프라인)**: 해당 없음 — 페이지네이션은 전체 페이지 이동(`<a>`), 브라우저 기본 처리

- **진입**: 헤더 링크(CPY-COMMON-007) / 직접 URL·검색 유입(index) / SCR-004 헤더

## 12. 분석 이벤트
커스텀 없음 — `page_view` 자동 수집 (PRD-15 §공통, 조회 이벤트 금지). 상세 이동은 내부 링크(UTM 없음)

## 13. 비기능
- **성능**: LCP ≤2.5초 — 카드 12개는 DOM 렌더(이미지 없음), 아바타만 next/image 소형(고정 `sizes`, 화면 밖 lazy 기본). LCP 후보 = h1 또는 첫 카드 텍스트
- **위생**: h1 1개 · `<main>/<section>/<ul>` · 전 콘텐츠 서버 렌더, 이 페이지에 `"use client"` 없음 (JS 비활성에서 목록·링크·페이지네이션 전부 동작 — shadcn `Pagination`은 `<nav>/<ul>/<li>/<a>` 순수 마크업이라 클라이언트 컴포넌트가 아니다)
- **메타데이터**: PRD-04 표 `/workflows` — canonical `/workflows` (`?page≥2`도 동일 — 첫 페이지만 색인), 사이트맵 포함 (컷 시 제거)
- **보안**: 읽기 전용, anon 키 — RLS "public read"가 노출 규칙 (PRD-05·09)

## 15. 접근성
항목 = `<a>` 1개(중첩 없음), 접근 가능한 이름 = 제목 텍스트 · 아바타 `alt=""`(인접 핸들 텍스트가 이름) · 페이지네이션 링크·CTA 44×44(shadcn 기본 아이콘 버튼은 32~36px라 `min-h-11 min-w-11`로 보정) · 현재 페이지 `aria-current="page"` · Tab 순회 + Enter 이동 + 포커스 링 · 대비 4.5:1
