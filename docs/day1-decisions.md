# Day 1 확정 — Stackd (2026-08-12)

> Day 2 기획서·Day 3 PRD가 참조하는 단일 소스. 3차 아이디어로 grill 통과·확정. 앞선 2회 폐기 기록은 하단 부록에 보존.

## 서비스 정의

- **서비스명**: Stackd (스택드) — `stackd.kr`
  - 의미: **Stack + car·d = "스택이 담긴 카드"**. 겉으로는 *stacked*(스택이 갖춰졌다)로도 읽히는 이중 의미. "card"를 직설로 노출하지 않아 명함 관리 서비스(리멤버 등)와 카테고리가 겹치지 않음
  - Day 4(2026-08-15) 재검토: Flexstack·Vitae·Emboss·Pair 등 비교 후 **유지 확정** — 혼자 씀·AI 스택·명함형 카드 세 조건을 가장 짧게 담는 이름. "명함"은 카테고리가 아니라 디자인 은유로만 사용
- **한 줄**: 내 AI 스택을 자랑할 무대 — 설정을 붙여넣으면 공유하고 싶어지는 스택 카드가 나온다
- **형태**: AI 스택 카드 생성기 (한국어 UI + 영어 카드 출력, 비로그인, 클라이언트 생성) → v2에서 갤러리(플랫폼)로 성장

## 문제 / 타겟

- 문제: AI 세팅을 보여주고 싶은 개발자가 많은데(GitHub repo·dotfiles 공유가 증거) 보여줄 **무대**가 없다 — repo는 투박하고 읽는 사람도 없음
- 타겟: Claude Code 등 AI 코딩 도구를 진지하게 쓰는 개발자·메이커 (한국 우선, 카드는 영어라 글로벌 확장 여지)

## 핵심 가설

> 검색·선택(기본) 또는 붙여넣기 파싱(보조)으로 아름다운 스택 카드가 한 번에 나오면, **만들고(전환) 공유한다(확산)** — 카드 하단 "나도 만들기" 링크가 확산 루프가 된다.

## 경쟁 / 차별점

| 기존 | 빈틈 |
|---|---|
| 개인 GitHub repo·dotfiles 공유 (workdd, thrawn01 등 다수) | 수요의 증거일 뿐, 무대가 아님 — 읽기 어렵고 발견 안 됨 |
| Claude-Config (HN) 등 설정 버전관리 도구 | 관리 도구지 쇼케이스가 아님 |
| 스킬 마켓플레이스 (6.3만 리스팅), stackshare.io/agent-skills | 도구가 주인공 — **사람이 주인공인 스택 쇼케이스는 공석** |

- 차별점 1줄: "도구 목록 사이트는 많지만, '이 사람의 스택'을 아름답게 보여주는 곳은 없다 — dotfiles 문화의 AI 버전"

## ① 킬 크라이테리아 (판정일 = 런칭 + 14일)

1. **생성 전환율**: `card_create` 사용자 / GA4 총 사용자 < **15%** → 피벗/중단
2. **확산 신호**: `card_share`(이미지 다운로드/링크 복사) 사용자 < **30명** → 확산 가설 기각
3. **최소 표본**: GA4 총 사용자 **300명** 미만이면 판정 보류 → 채널 1회 추가 게시 후 1주 연장

측정 정의 (Day 3 이벤트 스펙에 반영):
- `card_create`: 카드 미리보기 도달 시 1회 발화
- `card_share`: 다운로드 또는 링크 복사 클릭
- 카드 경유 유입: 카드 하단 "나도 만들기" 링크에 `utm_source=card` — 확산 루프 작동의 직접 증거 (판정 보조 지표)
- 재방문은 킬 기준이 아님 — 이 제품의 생존 지표는 재방문이 아니라 확산 루프

## ⓪ 언어·시장 / ② 중점 축 / ③ 유입 전략

- **언어·시장**: UI 한국어 + 카드 출력물 영어 기본 (스킬·도구명이 어차피 영어 — 카드가 X 등에서 돌면 글로벌 유입은 보너스). i18n은 backlog
- **중점 품질 축**: **애니메이션·비주얼** — 카드의 비주얼이 곧 제품("공유하고 싶어지는"이 기능 요구사항)
  - 우선 원칙: **"비주얼 vs 성능 충돌 시 성능 승"** (LCP 2.5초 예산 고정)
- **유입 전략**: **입소문·공유 주채널** (카드 확산 루프가 제품에 내장) + 커뮤니티 초기 부스트(디스콰이엇·GeekNews — 런칭 포스트 자체가 "내 스택 카드" 자랑 글). 검색은 기본 메타데이터 수준으로 경량화

## v1 스코프 힌트 (Day 2에서 SCR로 확정)

- 입력: **검색·선택이 기본** (큐레이션 카탈로그 100~200개 — 공식 마켓플레이스+awesome 리스트에서 반나절 수집, Day 2 콘텐츠 판정 포함), 없으면 직접 입력, 붙여넣기 파싱은 보조 기능
- 출력: 스택 카드 (클라이언트 이미지 생성 → **백엔드 0**), 카드 하단 "나도 만들기" 루프
- 카탈로그가 낡아도 직접 입력 경로가 있어 서비스가 죽지 않음 — 유저 직접 입력분은 카탈로그 후보로 수집(v2 성장 구조)
- backlog: 호스팅형 카드 URL(백엔드 필요 — Day 2 판정), 갤러리/탐색, i18n, codex·gemini 등 멀티 도구 프리셋
- 0번 카드 = 본인 세팅, 시드 = 커뮤니티 게시 1회 — 콜드 스타트 없음

## grill 기록 (v3)

- Q1 언어·시장 → UI 한국어+카드 영어로 확정
- Q2 1회성 지적 → 재방문 대신 확산(card_share·utm_source=card)을 킬 기준으로 — 동의
- Q3 파싱 리스크 → 검색·선택 기본, 파싱은 보조로 강등 (파싱 실패해도 서비스 생존)
- Q4 "첫 시작 고민" → 실행 걱정으로 해소 (0번 카드=본인, 시드=런칭 포스트, 이후는 루프)
- 무너진 가설 없음 — 통과

# 부록 — 폐기 기록 (같은 날 2회 번복)

## 타임라인 (2026-08-12, 시간순)

1. **1차 아이디어 = 구독 관리(서빗)**: 브레인스토밍 → 경쟁 조사 → 산출물 4개 확정
2. grill 중 1차 흔들림("웹은 유입 안 될 것, 앱이어야") → 반박·보완으로 **회복, grill 통과** — 이 흔들림은 폐기 사유가 아님
3. 서비스명 서빗·subit.kr 확정, 문서 기록까지 완료 (도메인 구매 직전)
4. **폐기 결정** — grill과 무관하게 이후에 발생. 사유: 왓섭 경쟁 부담 + 원한 방향 아님 ← 여기서 "원하는 방향 = 어디에도 없는 것 + 교육 확장"이 처음 언어화됨
5. **2차 아이디어 = CC 맞춤 세팅 키트**: 그 방향으로 재탐색, 형태·타겟·축까지 확정
6. **철회** — grill Round 1(유지보수·플랫폼 리스크·진단 설계·타겟 검증 4문) 답변 도중 "이것도 원한 방향이 아님"
7. Day 1 초기화 결정 → 기록 전부 삭제(git restore) → **기록 보존이 낫다고 재판단, 경위 포함 복구**
8. **방법 전환**: 후보 필터링 대신 "미래에 살기"(본인이 앞서 있는 지점에서 역산) — 위치 3개 확인(AI 오케스트레이션 일상화 / AI 네이티브 1인 출시 프로세스 / 기록 자동화)
9. 후보 A(스택 공유)·E(여정 타임라인)에 직감 반응 → 조사 결과 E는 레드오션, A를 도구형("스택 카드 생성기")으로 뒤집어 콜드 스타트 해소 → **"만들고 싶다" + grill 통과 동시 성립 → Stackd 확정**

**교훈**: 두 번 죽인 것은 grill의 논리가 아니라 명시된 적 없는 본인 기준("내 방식을 보여주고 싶다"는 정체성·과시형 프로덕트 지향). 관리 도구형 아이디어는 이 기준에서 반복 탈락했다.

## 폐기 v1 — 구독 관리 "서빗(Subit)" 요약

- 컨셉: 비로그인 구독 지출 대시보드 (한국어 웹, localStorage). 차별점: "가입도 연동도 없이 30초 — 한국 구독 프리셋(요금제·가격)"
- 경쟁 조사: 왓섭(연동 앱, 진입장벽 높음) / 모두계산(1회성 계산기) / SubTracker 등(영어권 전용) — "한국어 비로그인 웹 트래커" 공석 확인
- 확정했던 산출물: 한국어 시장 / 전환 15%(`dashboard_complete`=구독 3개 입력)·재방문 20명·표본 300명 / 애니메이션·비주얼 축("비주얼 vs 성능 충돌 시 성능 승") / 검색 주채널(키워드: 구독료 계산기·구독 관리 사이트·구독 정리·월 고정비 계산·구독 지출 확인) + 커뮤니티 부스트
- grill 보완: 타겟="점검 계기가 온 사람", 재방문 장치=결제일 캘린더, 프리셋에 요금제·가격 포함, 판정-채널 역할 분리, 가설에서 "공유" 제거
- 폐기 사유: 왓섭 경쟁 부담 + 원한 방향 아님
