## Day 1 (2026-08-12) — 아이디어 검증 grill

### ① 서빗(구독 관리) — Round 1 (06:55 UTC)

- **Q1 문제가 실재하는가**: "구독비를 모른다"는 알 방법이 없어서가 아니라 굳이 안 봐서 아닌가. 타겟은 "모르는 사람"인가 "알고 싶은 순간이 온 사람"인가?
  - **답**: 알고 싶은 순간이 온 사람
  - **이유**: "굳이 안 보는 사람"은 도구가 생겨도 안 쓴다. 계기가 온 사람으로 좁혀야 "구독 정리" 검색 유입과 타겟이 정확히 일치하고, "모든 20~30대"라는 방어 불가능한 전선에서 물러날 수 있음
- **Q2 재방문이 왜 일어나는가**: 본질이 1회성 계산기 — 두 번째 방문의 구체적 이유는?
  - **답**: (a) 재방문 장치 v1 포함 — 다음 결제일 캘린더 뷰
  - **이유**: 캘린더 뷰는 이미 입력한 데이터에서 공짜로 나오는 화면이라 스코프 비용이 거의 0인데, "월초마다 볼 이유"를 만들어줌. 기준을 빼는 (b)는 킬 크라이테리아를 스스로 무력화
- **Q3 "30초 입력"은 정말 30초인가**: 요금제 기억 안 나는 마찰을 프리셋이 어떻게 해결?
  - **답**: 프리셋 = 서비스명 + 요금제별 현재 가격까지
  - **이유**: 서비스명만 프리셋이면 "내가 프리미엄이었나?"에서 이탈 — 가격까지 있어야 탭 2번 = 입력 완료가 되어 "30초"가 카피가 아니라 사실이 됨. 유지보수 부담은 한국 주요 구독 30~50개 한정으로 상쇄
- **Q4 검색 주채널과 2주 판정의 시간 모순**: 신규 도메인이 2주 안에 검색 노출될 리 없다 — 판정 데이터는 사실상 100% 커뮤니티. 킬 크라이테리아는 무엇을 검증하나?
  - **답**: (미답변 — 답변 작성 중 "웹으론 유입이 안 될 것, 앱이어야" 흔들림 발생)
- **Q5 "공유"는 가설인가 기능인가**: 공유가 가설이면 v1에 공유 기능이 있어야 검증 가능
  - **답**: Round 2에서 — 공유는 디자인 품질의 부산물로, 일어나면 보너스 신호
  - **이유**: 전용 공유 기능(카드 이미지·OG 동적 생성)은 SCR 1개 이상을 먹는데, 가설 검증엔 "스크린샷 찍고 싶어지는 결과 화면"까지만으로 충분. 검증 안 된 가설에 화면을 미리 지불하지 않음

## Day 2 (2026-08-13) — MVP 기획서 스코프 방어 grill

### Round 1 (7문)

- **Q1 SCR-02(파싱) 정말 남기나**: 컷 1순위 화면에 반나절~1일을 왜 쓰나?
  - **답**: 잔류 — 우선 Claude Code 유저 대상으로만
  - **이유**: 일일이 검색·선택으로 담는 것보다 붙여넣기가 빠름(속도 보완이 잔류 가치) + "설정 붙여넣기 → 카드"는 데모 GIF 한 방이 나오는 런칭 포스트 후킹 소재. 비 Claude Code 유저 처리가 불명확한 리스크는 대상 한정으로 제거. Day 9 컷 1순위 지위는 유지
- **Q2 공유 링크의 OG 미리보기**: 백엔드 0이면 모든 카드의 OG가 동일 정적 이미지 — 확산 첫 접점에서 카드가 안 보인다
  - **답**: (b) next/og `ImageResponse`로 동적 OG 생성 — 백엔드 판정을 "**DB·인증·저장소 0**"으로 재정의
  - **이유**: 카드 비주얼이 제품인데 확산 루프의 첫인상(타임라인 미리보기)이 로고 한 장이면 가설 검증을 스스로 방해 — 링크 확산이 사실상 죽고 PNG 의존이 됨. next/og는 Vercel 내장이라 고정비 0·운영 부담 0으로, "백엔드 0"의 취지(비용·복잡도 방어)는 그대로 지켜짐. (a)는 확산 절름발이, (c)는 킬 크라이테리아 전제 파괴
- **Q3 URL 인코딩 페이로드**: 카탈로그 id 참조 vs 텍스트 자체 포함
  - **답**: 텍스트 자체 포함 (+압축)
  - **이유**: id 참조는 카탈로그를 수정·삭제하는 순간 이미 뿌려진 옛 링크의 카드가 깨짐 — 확산 루프의 신뢰는 "한 번 공유된 카드는 영원히 재현"에서 나옴. 직접 입력 항목은 어차피 텍스트라 단일 포맷으로 통일됨. 12개 상한이면 압축 후 수백 자 = URL 한계(~2,000자) 안이라 단점(URL 길이)이 실害 없음
- **Q4 `/c` 임의 텍스트 렌더 악용**: 서버 검증이 불가능한 구조에서 어디까지 방어?
  - **답**: 구조적 방어만
