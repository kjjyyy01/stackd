## 보조 지표 (판정 기준 아님 — 원인 해석용)

| 지표 | 측정 | 실측 | 읽는 법 |
|---|---|---|---|
| `card_preview` → `card_create` 낙차 | 두 이벤트 사용자 수 비 | preview 1명(4회) → create 0명 | 낙차가 크면 **로그인 벽의 비용**. ①이 미달인데 이 값이 크면 제품 실패가 아니라 게이트 위치 문제 |
| `step_add` 발화 사용자 | 사용자 수 | 0명 | 단계를 담지도 않았는가(가치 전달 실패) vs 담고도 저장을 안 했는가(빌더 마찰)를 가른다 |
| `card_reshare` | 사용자 수 | 0명 | 타인이 남의 카드를 퍼뜨린 증거. 라이브러리·상세의 확산 기여 |
| `login` | 사용자 수 | 0명 | 로그인 퍼널 통과량 |
| `utm_source` 분해 | threads / geeknews / disquiet / card / (direct) | 세션 60: (direct) 35 · threads 13 · disquiet 9 · m.facebook.com 2 · vercel.com 1 · geeknews 0 · **card 0** (세션 소스/매체 기준) | 어느 채널이 표본을 만들었는가. 카드 경유(`utm_source=card`)는 확산 루프 작동의 직접 증거 |
